# depo

Basit bir PHP kullanıcı giriş paneli örneği.

## Özellikler

- Oturum açtıktan sonra profil ad-soyad ve şifre bilgilerini güncelleyebileceğiniz bir "Profil Ayarları" bölümü.
- Yönetici olarak yeni üyeler adına PDF formatında raporlar yükleyebileceğiniz "Raporlarım" menüsü.
- Yüklediğiniz raporların listesi ve hızlıca görüntüleyebilmek için bağlantılar.

## Kurulum

1. PHP 8 veya üzeri bir sunucu/donanım ortamı hazırlayın.
2. Depoyu web sunucunuzun kök dizinine alın.
3. Tarayıcıdan `index.php` dosyasına gidin.
4. PDF raporlarını yüklemek için `uploads/` klasörünün web sunucusu tarafından yazılabilir olduğundan emin olun.
