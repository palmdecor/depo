# DataHub Platformu

Bu depo, FastAPI + MySQL tabanlı bir backend ve Next.js + TailwindCSS tabanlı bir
frontend içeren uçtan uca DataHub sistemini barındırır.

## Dizinyapısı

- `datahub/` – FastAPI backend kodları
- `datahub-frontend/` – Next.js kontrol panelleri

Her dizindeki README dosyalarında kurulum ve çalıştırma adımlarını bulabilirsiniz.
