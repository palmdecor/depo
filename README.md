# depo

Basit bir PHP kullanıcı giriş paneli örneği.

## Kurulum

1. PHP 8 veya üzeri bir sunucu/donanım ortamı hazırlayın.
2. Depoyu web sunucunuzun kök dizinine alın.
3. Tarayıcıdan `index.php` dosyasına gidin.

## Demo Hesap

- **Kullanıcı adı:** `demo`
- **Şifre:** `secret123`

Giriş yaptıktan sonra `dashboard.php` sayfasına yönlendirilirsiniz. "Çıkış Yap" butonuyla oturumu kapatabilirsiniz.
